# Architecture

`LoadingPlanModels` là domain model serializable; `PlanValidation` chịu trách nhiệm migration schema và integrity. `GridPlacement` kiểm tra bounds, collision, quantity, rotation, support và stackability bằng tọa độ nguyên Cột/Hàng/Tầng. `PlanIntelligence` derive completeness/weight/health và cung cấp heuristic placement deterministic. `PlanPersistence` validate-before-write, atomic save, backup recovery, import preview và cô lập file lỗi. `ContainerLoadingApp` điều phối workflow, undo/redo, debounced autosave, camera và visualizer; `ContainerLoadingMobileUI` dựng uGUI responsive. `PdfExportSystem` tạo báo cáo A4 Unicode nhiều trang. `AppUpdateService` kiểm tra GitHub Releases không token và không chặn startup. Android bridge xử lý picker, content URI và share sheet.
